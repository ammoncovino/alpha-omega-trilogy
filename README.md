## The Books

### Book One — The Alpha-Omega Lens
*18 chapters + Preface + Foundation + Appendix A (Verification Doors)*

The foundational text. Introduces the Alpha-Omega Lens — a structural tool for analyzing how systems of power, enforcement, peace, war, and religion operate beneath their surface narratives.

*40 chapters across 8 Parts + Verification Doors Appendix*

*Intentionally minimal*

The reader becomes the lens. A single-page culmination — the framework is now yours to apply.

## How to Use This

**Read it.** Start with Book One. The lens builds chapter by chapter.

**Test it.** Pick any system — a government, a religion, a corporation, a relationship — and apply the lens. If the framework holds, it holds. If it doesn't, it doesn't. That's the verification door.

**Feed it to an LLM.** Upload the trilogy PDF to any large language model and ask it to apply the Alpha-Omega Lens to any topic. The structural analysis is reproducible.
