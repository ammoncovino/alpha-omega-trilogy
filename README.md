## Repository Structure

The system has 5 layers beyond the books themselves:

### `governance/` — Rules, Boundaries, Distribution
How the lens operates, stays locked, and gets distributed to institutions.

- **`core/`** — Canonical governance bundle, locked definitions, boundary conditions
- **`distribution-editions/`** — Target-specific packages (OpenAI, Academic, Regulatory, Master)
- **`release-management/`** — Brand cover, public summary, cover letter, release log, submission checklist, changelog template, signed release, checksum verification
- **`zip-packages/`** — Complete distribution and external release archives

### `lens-tools/` — Portable Analysis Frameworks
Tools anyone can use to apply the lens to songs, businesses, speeches, or systems. The "put this in your LLM, this is what it does" layer.

- What This Lens Sees, Meaning Lens Template, WRITE IT IN RED Lens
- Meaning Lens prompt cards and packages
- Business Lens, Structural Lens Platform Overview
- One-Page Orientation

### `ai-layer/` — LLM Routing, Refusal Grammar, Canvases
Protocols that let AI carry the lens — routing prompts, refusal boundaries, canonical canvas compilations, and the master orientation control guide.

### `supporting-materials/` — Narratives, Archives, Outreach, Frameworks

- **`narratives/`** — The Glass, A Unified Theory of Perception, Five Rings crossover, Math and Universal Laws, Tree, Ants Butterflies and Roaches
- **`thread-archives/`** — Christ as a Container, Layered Reality, Master Governing Key Thread, Governance Thread, Chat Export

### `earlier-drafts/` — Manuscript Versions & Archives
27 earlier manuscript versions, reader editions, locked verbatim copies, condensed editions, and canonical artifacts — the full revision history.

## How to Use This

**Read it.** Start with Book One. The lens builds chapter by chapter.

**Test it.** Pick any system — a government, a religion, a corporation, a relationship — and apply the lens. If the framework holds, it holds. If it doesn't, it doesn't. That's the verification door.

**Feed it to an LLM.** Upload the trilogy PDF to any large language model and ask it to apply the Alpha-Omega Lens to any topic. The structural analysis is reproducible. See the `ai-layer/` folder for routing prompts and canvas protocols.

**Use the lens tools.** The `lens-tools/` folder contains portable analysis templates you can use immediately — or load into any AI assistant.
